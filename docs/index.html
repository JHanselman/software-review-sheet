    Write a software review

    A guided version of the MaRDI code review template for reviewing the software that comes with a mathematical paper. No LaTeX needed.

    1. Fill in the parts below. Click any dotted label to see what the guidelines say about it.
    2. Your work is kept in this browser automatically. Use File → Save to keep a copy or move it to another computer.
    3. Download the result as a PDF, or as a LaTeX project you can open on Overleaf.
